# CS-305-Software-Security

The client, Artemis Financial, is a financial consulting company requiring modernized security for the web application to safeguard sensitive financial records, enforcing encrypted communications with HTTPS/TLS, and to ensure data integrity using SHA-256 cryptographic checksums. In security evaluation, I audited out-of-date dependencies, addressed CVEs, and applied principle of defense in depth by configuring a Java KeyStore for SSL/TLS. I, also, used OWASP Dependency-Check Maven plugin. When navigating through vulnerability reports and configuring suppression file for false positives, presented initial challenges, I made sure the app remained both functional and secure with testing endpoints across encrypted connections and comparing baseline dependency scans to make sure new vulnerabilities showed up. Adhering to secure coding practices protects the organizations reputation, keeps up with regulatory compliance, and keeps the client's trust. This project produced a comprehensive vulnerability assessment report, securing coding docs, and refactoring Spring Boot code that can demonstrate to future employers a proven capability to identify risks, apply cryptographic standards, and secure enterprise software architectures.
